# X-Mindmap 编辑功能指南

## 🎯 功能概述

X-Mindmap 现在支持完整的编辑功能，让您可以直接在思维导图上进行交互式编辑，包括：

- ✏️ **节点文本编辑** - 双击节点即可编辑文本
- ➕ **添加节点** - 选中父节点后添加子节点
- ➖ **删除节点** - 选中节点后删除（根节点除外）
- 🎯 **节点选择** - 单击选择节点，显示选中状态
- 🔄 **实时更新** - 编辑后自动更新 Markdown 数据

## 🚀 快速开始

### 1. 基础设置

```vue
<template>
  <view>
    <x-mindmap 
      :data="mindmapData" 
      :height="500"
      :show-toolbar="true"
      :editable="true"
      @edit-mode-change="onEditModeChange"
      @data-change="onDataChange"
    />
  </view>
</template>

<script>
export default {
  data() {
    return {
      mindmapData: `# 我的思维导图
## 分支1
- 内容1
- 内容2
## 分支2
- 内容3`
    }
  },
  methods: {
    onEditModeChange(editMode) {
      console.log('编辑模式:', editMode);
    },
    onDataChange(newData) {
      this.mindmapData = newData;
      console.log('数据已更新');
    }
  }
}
</script>
```

### 2. 操作步骤

1. **开启编辑模式**
   - 点击工具栏的编辑按钮（✎图标）
   - 按钮会变为蓝色，表示编辑模式已开启
   - 思维导图容器会显示蓝色边框

2. **选择节点**
   - 单击任意节点进行选择
   - 选中的节点会显示蓝色边框和文字

3. **编辑节点文本**
   - 双击已选中的节点
   - 会弹出输入框，可以修改文本
   - 按 Enter 确认，按 Esc 取消

4. **添加节点**
   - 选中要作为父节点的节点
   - 点击工具栏的添加按钮（⊕图标）
   - 新节点会作为子节点添加

5. **删除节点**
   - 选中要删除的节点
   - 点击工具栏的删除按钮（⊖图标）
   - 注意：根节点无法删除

## 📋 完整示例

```vue
<template>
  <view class="page">
    <view class="header">
      <text class="title">可编辑思维导图</text>
    </view>
    
    <view class="mindmap-container">
      <x-mindmap 
        :data="mindmapData" 
        :height="400"
        :show-toolbar="true"
        :editable="true"
        theme="default"
        @ready="onReady"
        @edit-mode-change="onEditModeChange"
        @node-click="onNodeClick"
        @node-add="onNodeAdd"
        @node-delete="onNodeDelete"
        @node-edit="onNodeEdit"
        @data-change="onDataChange"
      />
    </view>
    
    <view class="status">
      <text>编辑模式: {{ editMode ? '开启' : '关闭' }}</text>
      <text v-if="selectedNode">选中: {{ selectedNode.content }}</text>
    </view>
  </view>
</template>

<script>
import XMindmap from '@/uni_modules/x-mindmap/components/x-mindmap/x-mindmap.vue'

export default {
  components: { XMindmap },
  data() {
    return {
      editMode: false,
      selectedNode: null,
      mindmapData: `# 项目计划
## 第一阶段
- 需求分析
- 原型设计
## 第二阶段  
- 开发实现
- 测试验证`
    }
  },
  methods: {
    onReady() {
      uni.showToast({ title: '加载完成', icon: 'success' });
    },
    onEditModeChange(editMode) {
      this.editMode = editMode;
      uni.showToast({ 
        title: editMode ? '编辑模式开启' : '编辑模式关闭',
        icon: 'none' 
      });
    },
    onNodeClick(node) {
      this.selectedNode = node;
    },
    onNodeAdd(data) {
      uni.showToast({ title: '节点添加成功', icon: 'success' });
    },
    onNodeDelete(node) {
      uni.showToast({ title: '节点删除成功', icon: 'success' });
      this.selectedNode = null;
    },
    onNodeEdit(data) {
      uni.showToast({ title: '节点编辑成功', icon: 'success' });
    },
    onDataChange(newData) {
      this.mindmapData = newData;
      // 可以在这里保存到本地存储或服务器
      console.log('数据更新:', newData);
    }
  }
}
</script>

<style>

.title { font-size: 20px; font-weight: bold; }
.mindmap-container { 
  background: white; 
  border-radius: 8px; 
  padding: 20px; 
  margin-bottom: 20px; 
}
.status { 
  background: #f5f5f5; 
  padding: 10px; 
  border-radius: 4px; 
}
</style>
```

## ⚙️ 配置选项

### editable 属性
```vue
<x-mindmap :editable="true" />
```

### editConfig 配置
```vue
<x-mindmap 
  :editable="true"
  :edit-config="{
    allowAddNode: true,
    allowDeleteNode: true,
    allowEditText: true,
    allowDragNode: false
  }"
/>
```

## 🎯 事件说明

| 事件名 | 参数 | 说明 |
|--------|------|------|
| edit-mode-change | Boolean | 编辑模式切换 |
| node-click | Object | 节点点击 |
| node-add | Object | 节点添加 |
| node-delete | Object | 节点删除 |
| node-edit | Object | 节点编辑 |
| data-change | String | 数据变化（Markdown格式） |

## 💡 使用技巧

1. **数据持久化**: 监听 `data-change` 事件保存数据
2. **操作反馈**: 使用 `uni.showToast` 提供用户反馈
3. **状态管理**: 跟踪编辑模式和选中节点状态
4. **样式定制**: 通过 CSS 自定义编辑模式的视觉效果

## 🔧 注意事项

- 编辑功能仅在 H5 和 App 平台完全支持
- 小程序平台需要支持 renderjs
- 根节点无法删除，只能编辑文本
- 编辑后的数据会自动转换为 Markdown 格式
