# X-Mindmap 组件使用说明

## 🚀 快速开始

### 第一步：安装插件

1. **下载插件**
   - 将 `x-mindmap` 文件夹放入项目的 `uni_modules` 目录

2. **安装依赖**
   ```bash
   cd uni_modules/x-mindmap
   pnpm install
   ```

3. **引入组件**
   ```vue
   <script>
   import XMindmap from '@/uni_modules/x-mindmap/components/x-mindmap/x-mindmap.vue'
   
   export default {
     components: {
       XMindmap
     }
   }
   </script>
   ```

## ✏️ 编辑功能

### 启用编辑模式

```vue
<template>
  <view>
    <view class="edit-status">
      <text>编辑模式: {{ editMode ? '开启' : '关闭' }}</text>
      <text v-if="selectedNode">选中节点: {{ selectedNode.content }}</text>
    </view>
    
    <x-mindmap 
      :data="mindmapData" 
      :height="500"
      :show-toolbar="true"
      :editable="true"
      @edit-mode-change="onEditModeChange"
      @node-click="onNodeClick"
      @node-add="onNodeAdd"
      @node-delete="onNodeDelete"
      @node-edit="onNodeEdit"
      @data-change="onDataChange"
    />
  </view>
</template>

<script>
export default {
  data() {
    return {
      editMode: false,
      selectedNode: null,
      mindmapData: `# 可编辑思维导图

## 操作说明
- 点击编辑按钮进入编辑模式
- 单击节点选择
- 双击节点编辑文本
- 选中节点后可添加或删除

## 示例内容
- 这是一个示例节点
- 您可以编辑这些内容`
    }
  },
  methods: {
    onEditModeChange(editMode) {
      this.editMode = editMode;
      uni.showToast({
        title: editMode ? '编辑模式开启' : '编辑模式关闭',
        icon: 'none'
      });
    },
    
    onNodeClick(node) {
      this.selectedNode = node;
      console.log('选中节点:', node.content);
    },
    
    onNodeAdd(data) {
      console.log('添加节点:', data);
      uni.showToast({
        title: '节点添加成功',
        icon: 'success'
      });
    },
    
    onNodeDelete(node) {
      console.log('删除节点:', node.content);
      this.selectedNode = null;
      uni.showToast({
        title: '节点删除成功',
        icon: 'success'
      });
    },
    
    onNodeEdit(data) {
      console.log('编辑节点:', data);
      uni.showToast({
        title: '节点编辑成功',
        icon: 'success'
      });
    },
    
    onDataChange(newData) {
      this.mindmapData = newData;
      console.log('数据更新:', newData);
      
      // 可以在这里保存到本地存储
      uni.setStorageSync('mindmapData', newData);
    }
  }
}
</script>

<style>
.edit-status {
  padding: 10px;
  background: #f5f5f5;
  margin-bottom: 10px;
  border-radius: 8px;
}
</style>
```

### 编辑操作说明

1. **进入编辑模式**
   - 点击工具栏的编辑按钮（✎图标）
   - 按钮变蓝表示编辑模式已开启

2. **选择节点**
   - 单击任意节点进行选择
   - 选中的节点会显示蓝色边框

3. **编辑文本**
   - 双击选中的节点
   - 在弹出的输入框中修改文本
   - 按 Enter 确认，按 Esc 取消

4. **添加节点**
   - 选中要作为父节点的节点
   - 点击工具栏的添加按钮（⊕图标）

5. **删除节点**
   - 选中要删除的节点
   - 点击工具栏的删除按钮（⊖图标）
   - 注意：根节点无法删除

## 📱 响应式设计

### 移动端适配

```vue
<template>
  <view class="mindmap-wrapper">
    <x-mindmap 
      :data="data" 
      :height="isMobile ? 350 : 500"
      :show-toolbar="!isMobile"
      :spacing="isMobile ? mobileSpacing : desktopSpacing"
      :font="isMobile ? mobileFont : desktopFont"
    />
  </view>
</template>

<script>
export default {
  data() {
    return {
      isMobile: false,
      mobileSpacing: {
        horizontal: 60,
        vertical: 4,
        paddingX: 6
      },
      desktopSpacing: {
        horizontal: 100,
        vertical: 8,
        paddingX: 12
      },
      mobileFont: {
        baseSize: 12,
        maxSize: 16,
        minSize: 10
      },
      desktopFont: {
        baseSize: 16,
        maxSize: 24,
        minSize: 14
      }
    }
  },
  mounted() {
    // 检测设备类型
    const systemInfo = uni.getSystemInfoSync();
    this.isMobile = systemInfo.platform === 'ios' || systemInfo.platform === 'android';
  }
}
</script>
```

## 💾 数据持久化

### 本地存储

```vue
<script>
export default {
  data() {
    return {
      mindmapData: ''
    }
  },
  mounted() {
    // 加载保存的数据
    this.loadData();
  },
  methods: {
    loadData() {
      const savedData = uni.getStorageSync('mindmapData');
      if (savedData) {
        this.mindmapData = savedData;
      } else {
        this.mindmapData = this.getDefaultData();
      }
    },
    
    saveData(data) {
      uni.setStorageSync('mindmapData', data);
      uni.showToast({
        title: '数据已保存',
        icon: 'success'
      });
    },
    
    onDataChange(newData) {
      this.mindmapData = newData;
      this.saveData(newData);
    },
    
    getDefaultData() {
      return `# 我的思维导图
## 默认内容
- 这是默认的思维导图内容
- 您可以开始编辑`;
    }
  }
}
</script>
```

### 云端同步

```vue
<script>
export default {
  methods: {
    async saveToCloud(data) {
      try {
        const response = await uni.request({
          url: 'https://your-api.com/mindmap',
          method: 'POST',
          data: {
            content: data,
            timestamp: Date.now()
          }
        });
        
        if (response.statusCode === 200) {
          uni.showToast({
            title: '云端保存成功',
            icon: 'success'
          });
        }
      } catch (error) {
        console.error('云端保存失败:', error);
        uni.showToast({
          title: '云端保存失败',
          icon: 'error'
        });
      }
    },
    
    async loadFromCloud() {
      try {
        const response = await uni.request({
          url: 'https://your-api.com/mindmap',
          method: 'GET'
        });
        
        if (response.statusCode === 200 && response.data.content) {
          this.mindmapData = response.data.content;
          uni.showToast({
            title: '云端加载成功',
            icon: 'success'
          });
        }
      } catch (error) {
        console.error('云端加载失败:', error);
      }
    }
  }
}
</script>
```

## 🐛 常见问题

### 1. 思维导图不显示

**可能原因**:
- 数据格式不正确
- 容器高度为 0
- 依赖未正确安装

**解决方案**:
```vue
<template>
  <!-- 确保容器有明确的高度 -->
  <view style="height: 400px;">
    <x-mindmap 
      :data="data" 
      :height="400"
      @error="handleError"
    />
  </view>
</template>

<script>
export default {
  methods: {
    handleError(error) {
      console.error('思维导图错误:', error);
      uni.showModal({
        title: '错误',
        content: '思维导图加载失败，请检查数据格式'
      });
    }
  }
}
</script>
```

### 2. 小程序中无法使用

**解决方案**:
在 `manifest.json` 中配置：
```json
{
  "mp-weixin": {
    "setting": {
      "renderjs": true
    }
  }
}
```

### 3. 编辑功能异常

**检查清单**:
- 确保设置了 `editable="true"`
- 确保开启了工具栏 `show-toolbar="true"`
- 检查是否监听了相关事件
